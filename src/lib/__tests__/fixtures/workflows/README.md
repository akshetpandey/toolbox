# Browser workflow fixtures

These fixtures exercise complete tool routes in `pnpm test:workflows`. The suite opens the downloaded files and checks their contents. It runs without downloading test inputs. For production screenshots, run `pnpm build` followed by `pnpm test:workflows --preview --screenshots /absolute/output/path`.

- `apollo.jpg` and `apollo.heic` are approximately 10-megapixel derivatives of NASA photograph AS11-40-5903 by Neil Armstrong. The JPEG was resized and tagged with test metadata. The HEIC was encoded with libheif. [NASA photo](https://eol.jsc.nasa.gov/SearchPhotos/photo.pl?frame=5903&mission=AS11&roll=40) · [Public domain source image](<https://commons.wikimedia.org/wiki/File:AS11-40-5903_-_Buzz_Aldrin_by_Neil_Armstrong_(full_frame).jpg>)
- `forest.mp4`, `portrait.mov`, `soundtrack.m4a`, and `intro.wav` are excerpts from _Big Buck Bunny_, © 2008 Blender Foundation, licensed under [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). The excerpts were cut and re-encoded or remuxed. `forest.mp4` is 1080p with AAC audio and test metadata. `portrait.mov` is cropped to portrait, uses HEVC, and has no audio track. The audio files use AAC and PCM. [Blender project](https://peach.blender.org/download/) · [1080p source excerpt](https://github.com/renesas-rz/media/tree/main/Big_Buck_Bunny)
- `inventory.xlsx` and `briefing.pptx` were made for these tests with OpenPyXL and python-pptx. They contain synthetic survey data, multiple sheets or slides, formulas, charts, and a slide image. The suite constructs a paginated DOCX with images and tables, selectable PDFs with mixed page orientations, a two-page raster scan, and an encrypted ZIP from the same assets.
